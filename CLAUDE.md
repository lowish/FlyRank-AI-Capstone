
# FlyRank AI Capstone

## Project Overview

This repository is part of the FlyRank AI Front-end AI Engineering internship.

The project will be developed incrementally throughout the internship using AI-assisted development workflows.

## Technology Stack

- React
- TypeScript
- Vite
- Node.js
- Claude Code

## Coding Conventions

- Write clean, readable, and maintainable code.
- Use TypeScript for type safety.
- Follow React functional component patterns.
- Use descriptive names for variables and functions.
- Keep components organized and reusable.
- Avoid unnecessary complexity and dependencies.
- Follow consistent formatting and naming conventions.

## Git Conventions

Follow Conventional Commits for all commit messages.

Examples:
- feat: add new functionality
- fix: resolve an issue
- docs: update documentation
- chore: configure project setup
- refactor: improve existing code

## AI Assistant Guidelines

- Review existing files before making changes.
- Follow the project's coding conventions.
- Explain significant changes.
- Avoid modifying unrelated files.
- Keep solutions simple and maintainable.
- Do not create commits unless requested.
